## Быстрый старт для проверяющего

1. Распаковать ZIP. Установленный Node.js 18+ достаточен, npm install не требуется.
2. Запустить start.cmd или node server.mjs.
3. Открыть http://127.0.0.1:8774.
4. Короткая демонстрация: http://127.0.0.1:8774/demo.html, кнопка «Запустить демо».
5. Плагин Figma: инструкция plugin/README.md. Для автономной версии импортировать plugin/manifest.json в Figma Desktop. Библиотека встроена. Версия из аккаунта Figma запрашивает комплектный plugin/library.json.

## Содержание

- plugin/: готовый плагин, исходники, библиотека и подтверждение проверки в Figma.
- examples/: три SVG, три редактируемых проекта, примеры полной и короткой палитры.
- README.md: запуск, возможности, цветовые роли и ограничения.
- ARCHITECTURE.md: устройство приложения и плагина.
- REQUIREMENTS.md: соответствие пунктам задания.
- demo.html: интерактивная демонстрация на отдельном холсте без перезаписи проекта.
- tests/: 17 проверок. Команда node --test tests/*.test.mjs.

Репозиторий: https://github.com/5eeee/sborka-svg-composer. Он закрытый: для ревью потребуется отдельное приглашение. Передача ZIP позволяет проверить проект без доступа к GitHub. localhost-ссылки работают после локального запуска, они не являются публичным хостингом.

## Ограничение, которое следует сообщить

Подбор основан на локальных смысловых правилах и контекстах. Внешний AI API не подключён. Для неизвестной метафоры редактор предлагает ручной выбор, не подставляет случайные объекты. AI использовался при разработке кода и разборе требований, подробнее в README.md.
