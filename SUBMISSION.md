# Комплект для Амиры

Статус: подготовлен, не отправлен.

В архиве приложение, автономный плагин, исходники модулей, библиотека, оригинальное ТЗ, три примера, демо и инструкция. Запуск: start.cmd или node server.mjs, затем http://127.0.0.1:8774. Node.js 18+, без установки зависимостей для запуска.

Публичный репозиторий: https://github.com/5eeee/sborka-svg-composer
Редактируемые макеты и компоненты: https://www.figma.com/design/aadh2KN9IgfjlrDEfzDLNM/Untitled

## Черновик сообщения

Амира, здравствуйте! Подготовил тестовое: редактор векторных композиций и плагин Figma. В комплекте исходники, инструкция запуска, короткое демо и три примера. Поддерживаются сборка по идее или списку названий, S/L, палитры, исходные фоны, перемещение и поворот предметов, слои и SVG-экспорт. Отдельно подготовлены редактируемые макеты для компьютера, планшета и телефона с библиотекой компонентов.

Подбор метафор работает локально по смысловым правилам и словарю выражений. Исходные векторы сохраняются, новые иллюстрации не генерируются. Код и описание архитектуры находятся в репозитории.
