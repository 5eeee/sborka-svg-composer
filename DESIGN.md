## Компоненты приложения

Обзор: https://www.figma.com/design/aadh2KN9IgfjlrDEfzDLNM/Untitled?node-id=71-11825

169 основных компонентов собраны из точных исходных слоёв: логотип, кнопки, поля, переключатели, палитры, иконки, холсты и три окна. Сохранены размеры для разных ширин интерфейса, исходные иллюстрации и параметры текста. В обзоре размещены экземпляры, основные компоненты вынесены отдельно. Доступны текстовые свойства у компонентов с собственным текстом и цветовые переменные с именами CSS приложения.

Готовые экраны сохранены отдельными редактируемыми слоями. Их элементы не переподключаются автоматически: массовое переподключение импортированных слоёв меняло их раскладку. Библиотека предназначена для повторного использования и дальнейшего проектирования.

## Проверка

Сводка сравнения компонентов находится в sources/components-pixel-validation.json. Изображения экспортируются из Figma при масштабе 1, затем сравниваются по видимым пикселям на фоне приложения. Проверка учитывает небольшие различия сглаживания, но выявляет изменение текста, размеров и обрезку.

Текстовые параметры сохранены непосредственно из исходников. Общие стили доступны в Figma как основа; автоматическое назначение стилей не применяется там, где оно меняет метрики шрифта. Оригинальные SVG остаются векторами.

Повторный перенос из приложения: node capture-build.mjs, затем node server.mjs и /capture.html?demo=1 с официальным HTML-to-Figma инструментом. В обычном index.html скрипта переноса нет.
