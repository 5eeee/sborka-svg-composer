# Соответствие исходному ТЗ

Реализованы два сценария ввода: по идее/метафоре и по всем явно названным компонентам. Используются только предоставленные SVG; новые предметы не генерируются. Подбор локальный, словарь выражений расширен; для неизвестной идеи есть ручной выбор.

Сохраняются исходные векторы, пропорции и относительные размеры предметов. S/L автоматически выбирает исходную детализацию. Доступны основные и монохромные фоновые роли, композиции без фоновых предметов, три исходные палитры, импорт собственной палитры и автоматическая перекраска.

Есть добавление, перемещение, поворот, дублирование, удаление и порядок слоёв. Форматы холста включают широкий, квадратный, вертикальный и свой размер. SVG-экспорт остаётся векторным; плагин добавляет редактируемые слои в Figma.

В комплекте запускаемый проект, демо, публичный репозиторий, архитектура, описание Codex как инструмента разработки и три примера. Отдельно созданы редактируемые макеты desktop/tablet/mobile с компонентами.

20 автоматических тестов. Поворот 15° подтверждён в SVG DOM. Сохранение исходного относительного масштаба и всех десяти названий проверено тестами и экспортированными проектами. Подробная история аудита: SPEC-AUDIT.txt; актуальный статус: FINAL-CHECK.md и CURRENT.json.

Ограничение: локальный анализ метафор не универсальная языковая модель. В исходном ТЗ нет обязательного конкретного AI API. Амире ничего не отправлено.
