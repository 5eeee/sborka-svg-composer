# Сверка с заданием

| Требование | Реализация |
| --- | --- |
| Веб сервис или плагин | Обе версии, общий редактор |
| Ввод смысла / метафоры | Локальный контекстный подбор, явные предметы и исключения; понятный отказ для неизвестного сюжета |
| Ручной выбор | Поиск и добавление из 10 сюжетов |
| Только предоставленная библиотека | 20 основных SVG S/L и 20 фоновых вариантов; произвольный SVG импорт отдельным действием |
| Геометрия | Исходные path сохранены, трансформации на внешней группе |
| S / L | Загружаются разные исходные объекты соответствующей детализации |
| Основные и фоновые объекты | Раздельный подбор, отдельные исходные SVG, строгая проверка цветовых ролей |
| Перемещение, копирование, удаление | Мышь, числовые поля, клавиатура и кнопки |
| Слои | Выбор, выше / ниже, фоновые объекты |
| Размер холста | Пресеты и свои размеры 200–5000 px |
| Три цветовые схемы | Исходные схемы Figma и импорт JSON |
| Экспорт SVG | Отдельные векторные группы без растеризации |
| Редактирование в Figma | Кнопка плагина создаёт нативные векторные слои |
| 2–3 примера | Три SVG и три редактируемых JSON в examples |
| Архитектура и AI инструменты | README.md и ARCHITECTURE.md |
| Репозиторий | Закрытый GitHub: https://github.com/5eeee/sborka-svg-composer; внешнему проверяющему нужен доступ |
| Демонстрация | Работающее 22-секундное прохождение в demo.html, 10 шагов; отдельный холст без сохранения |

Ограничение: автоподбор не универсальная языковая модель. Внешний платный API и ключи не подключены. Любой найденный объект можно добавить вручную. В задании не указан обязательный конкретный AI API, но качество интерпретации произвольных метафор следует учитывать при оценке.


Обновление 02.11.2026: подключены шесть оригинальных графических фонов холста из Figma. SVG находятся в assets/backgrounds, исходное ТЗ в sources/task-original.pdf. Ручные масштаб и поворот убраны по прямому указанию пользователя. Поворот предусмотрен оригинальным ТЗ, поэтому эта часть сознательно отличается от задания; трансформации можно выполнять после вставки в Figma.
