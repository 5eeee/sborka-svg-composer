# SVG Assembly

Тестовое для Студии Очень, получено от Амиры 02.11.2026.
Источник: Figma 4MCFttsSoP7hgQh29zq5G3, рабочая копия jEvpS675RI0kpKEN6B947R.
Содержание: локальный редактор композиций из исходных SVG, без генерации новых объектов.
Запуск: `node server.mjs`, затем http://127.0.0.1:8774.
Исходные экспорты сохранены в sources, происхождение и SHA-256 объектов в assets/manifest.json.
