# Сборка, плагин Figma

## Быстрый запуск из аккаунта Figma

https://www.figma.com/file/new?try-tool-resource-content-id=2137a770-4ae4-432e-8fb5-81003c111a93&try-tool-resource-type=gen_tool&type=design&mode=design

При первом запуске выберите `library.json` из этой папки. В ней все 40 оригинальных SVG. Облачный редактор Figma ограничивает размер загружаемого исходного кода плагина, поэтому библиотека загружается отдельным локальным файлом. Объекты не запрашиваются с внешнего сервера.

## Автономная версия для Figma Desktop

В Figma Desktop: Plugins → Development → Import plugin from manifest. Выберите `manifest.json` в этой папке. Затем запустите «Сборка» из Development. Библиотека встроена, отдельная загрузка не нужна. Интернет для библиотеки не требуется.

Плагин показывает полноценный редактор. Соберите композицию, проверьте S/L, цвета и слои, нажмите «Добавить в Figma». На странице появится новая композиция с редактируемыми векторными слоями. Существующие объекты страницы не изменяются.

Файлы `code.js` и `ui.html` готовы к запуску. Для пересборки: `node build-plugin.mjs`, затем `npx esbuild plugin/code.ts --outfile=plugin/code.js --target=es2017`.

Облачная версия: id `2137a770-4ae4-432e-8fb5-81003c111a93`, версия `43392c85da1f1c07c01a3cf0ec915e3629e52237`. Исходники для облачной версии: code-cloud.ts и ui-cloud.html.
