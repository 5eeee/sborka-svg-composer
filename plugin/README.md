# Плагин Сборка

## Установка из комплекта

1. Откройте любой свой файл в Figma Desktop.
2. Plugins → Development → Import plugin from manifest.
3. Выберите manifest.json в этой папке.
4. Plugins → Development → Сборка.

Векторы и интерфейс встроены. Интернет и локальный сервер не нужны. code.js и ui.html должны оставаться рядом с manifest.json.

## Использование

Введите идею или названия предметов. Кнопка с разноцветными искрами предлагает текст; «Собрать идею» собирает сцену. S/L меняет детализацию. Палитры перекрашивают объекты по ролям. Можно перемещать, поворачивать, дублировать и удалять предметы. «Добавить в Figma» создаёт новую редактируемую векторную композицию. Чужие слои не заменяются.

SVG и JSON сохраняются отдельными кнопками. Импорт своих SVG, палитр и проектов доступен из интерфейса. Примеры палитр находятся в ../examples.

## Разработка

В корне проекта: npm ci, npm test, npm run build:plugin. Исходная логика общая с веб-редактором. При переустановке существующего development plugin используйте тот же manifest.
