# Сценарий демонстрации

1. Введите «Обучение без отвлечений», нажмите «Собрать идею».
2. Переключите S и L и сравните детализацию.
3. Выберите бирюзовую схему. Загрузите examples/palette.json.
4. Добавьте лампу из библиотеки. Переместите её мышью, поверните через поле «Угол», продублируйте.
5. Измените порядок слоёв. Удалите копию, отмените действие.
6. Сохраните SVG и проект JSON. Откройте JSON обратно.
7. В плагине нажмите «Добавить в Figma». Раскройте созданный фрейм в панели Layers, выберите отдельный вектор.
8. Повторите для «Накопить на мечту» и «Работа с документами».

Рабочая демонстрация: запустите `node server.mjs`, откройте http://127.0.0.1:8774/demo.html и нажмите «Запустить демо». За 22 секунды выполняются 10 действий на отдельном холсте без перезаписи сохранённого проекта. После завершения можно управлять этим холстом вручную. Это интерактивная демонстрация, а не видеозапись.
