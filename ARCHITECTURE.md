# Как устроена Сборка

Это модульный монолит: один проект, внутри которого код разделён по задачам.
Монорепозиторий здесь не нужен: отдельных продуктов, серверных сервисов и независимых пакетов нет. Веб-редактор и плагин используют одну и ту же логику, поэтому исправления не приходится повторять дважды.

## Структура

- src/domain/selection.mjs: словарь, метафоры, явные названия и исключения.
- src/domain/layout.mjs: размещение предметов, единый масштаб и размеры холста.
- src/domain/palette.mjs: цветовые роли, проверка палитр и перекраска.
- src/domain/ids.mjs: идентификаторы без зависимости от браузерного crypto.
- src/ui/dialogs.mjs: окна импорта и уведомления.
- src/editor.mjs: состояние редактора и связь элементов интерфейса с логикой.
- src/styles/editor.css: базовые стили редактора и адаптация.
- src/styles/workspace-polish.css: актуальная геометрия рабочего окна, кнопки, независимая прокрутка и затухание краёв.
- app.js: короткая точка входа веб-версии.
- core.mjs: единая публичная точка входа логики для тестов и редактора.
- build-plugin.mjs: собирает те же модули через esbuild и упаковывает библиотеку для Figma. Внутренний код редактора больше не переписывается строковыми заменами.
- design-generator.ts: извлекает компоненты из проверенных слоёв макета, создаёт обзор и экспортирует образцы для проверки. Готовые экраны не переподключает.
- plugin/: готовые автономная и аккаунтная версии плагина.
- assets/: исходная векторная библиотека и фоны.
- sources/: исходное ТЗ, выгрузки Figma и подтверждения проверки.

## Как проходит работа

Пользователь вводит идею или названия. Модуль подбора выбирает существующие предметы, модуль раскладки ставит их на холст с единым масштабом, модуль палитры применяет цвета по ролям. Редактор показывает результат и даёт перемещать, поворачивать, копировать и удалять предметы. Экспорт сохраняет SVG; плагин добавляет его в Figma векторами.

Новые иллюстрации не генерируются. Метафоры разбираются локально: словарь тем и устойчивых выражений расширен. Для неизвестной идеи нужен ручной выбор; скрытых внешних API и ключей нет.

Для запуска достаточно Node.js 18+: node server.mjs. Зависимости esbuild и prettier нужны разработчику для пересборки и форматирования: npm ci, npm run build:plugin. Готовый редактор работает без npm install.

## Интерфейс

src/ui/workspace.mjs отвечает за сворачивание разделов, виды библиотеки и окончание запуска. Эти возможности используют общие стили и входят в обе версии плагина. Аккаунтная версия автоматически получает закреплённую публичную библиотеку; автономная версия содержит её внутри. responsive-flows.ts организует проверенные перенесённые экраны и связывает их в прототипе.

## Состояние и упаковка

state.idea хранит идею построенной сцены. draftIdea сохраняет несобранный текст отдельно, чтобы вариация существующей композиции не зависела от черновика. Экспорт SVG удаляет служебную рамку выделения и не содержит растровых изображений. Исходные векторы извлекаются по идентификатору, размеру S/L и роли; экземпляры переиспользуют исходные пути без изменения геометрии.
