# Архитектура

Browser -> core.mjs semantic matching / layout -> app.js SVG DOM -> SVG / project JSON.

Sources -> prepare_assets.py -> assets/{S,L}/{main,background} -> manifest.json.

Данные проекта находятся только в localStorage или скачанном JSON. Сервер раздаёт статические файлы, не содержит ключей и не открывает внешних API. Геометрия SVG сохраняется в исходных path, преобразования применяются к группе экземпляра.

build-plugin.mjs встраивает общий HTML/CSS, app.js и core.mjs в ui.html. Для автономного плагина библиотека сжимается gzip и делится между UI и sandbox, передача второй половины по сообщению boot/assets. Для облачного плагина библиотека загружается из локального library.json: исходный код с полной библиотекой превышает лимит запроса MCP.

UI передаёт очищенный SVG сообщением insert. Sandbox проверяет тип, размер, габариты и запрещённые элементы, создаёт новый фрейм через createNodeFromSvg и размещает его в текущей области просмотра. Существующие слои страницы не изменяются. Результат выбирается и получает relaunch. Ошибки возвращаются в UI, повторная вставка блокируется только на время операции.
