# Готовность к передаче

Проект подготовлен для проверки пользователем, не отправлен Амире.

Запуск: start.cmd или node server.mjs. Демо: /demo.html. Инструкция по плагину: plugin/README.md. Макеты и ссылки: DESIGN.md. Архитектура и принципы модулей: ARCHITECTURE.md. Соответствие ТЗ: REQUIREMENTS.md.

Репозиторий публичный по указанию пользователя: https://github.com/5eeee/sborka-svg-composer
В комплект включены исходники, готовый плагин, library.json, 46 SVG библиотеки, исходное ТЗ и три примера. Зависимости npm нужны только для разработки и повторной сборки, готовый веб-редактор запускается на Node.js 18+ без npm install.

20 тестов проходят. Адаптивность: 1440, 1024, 390 px. Поворот возвращён и оформлен. Связанные элементы интерфейса в макете выполнены экземплярами компонентов, текст и векторы редактируются.
