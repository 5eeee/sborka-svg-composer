# Сборка

Векторный редактор композиций и плагин Figma для тестового задания Студии Очень.

## Запуск

Нужен Node.js 18 или новее. Запустите start.cmd либо выполните node server.mjs, затем откройте http://127.0.0.1:8774. Для запуска готовой версии npm install не требуется.

## Как пользоваться

1. Введите идею, метафору или названия предметов и нажмите «Собрать идею».
2. Выберите детализацию S/L, формат холста и палитру. Можно загрузить свою цветовую схему.
3. Перемещайте предметы, меняйте угол в поле «Поворот», дублируйте, удаляйте и переставляйте слои. Соотношения размеров предметов сохраняются.
4. Скачайте SVG или сохраните проект JSON. В плагине можно добавить результат в Figma векторами.

Поддерживаются десять предметов в S/L, основные и монохромные фоновые варианты, шесть оригинальных графических фонов. Новые предметы не генерируются. Все явно перечисленные предметы учитываются.

## Метафоры

Работают тематические правила и словарь выражений. Примеры: «Войти в поток», «Разгрести завалы», «Включить голову», «Мысли на бумаге», «Копить на отпуск», «Протянуть руку», «Учиться никогда не поздно». Для неизвестной идеи предлагается ручной выбор. Это локальный подбор без внешнего AI API и скрытых ключей.

AI-инструмент разработки: Codex, для разбора задания, реализации, рефакторинга и проверки. Векторные иллюстрации взяты из предоставленной Figma, не сгенерированы AI.

## Структура и разработка

Проект — модульный монолит: один редактор и одна общая логика для веба и Figma. Причины и схема работы описаны в ARCHITECTURE.md.

- src/domain: подбор, раскладка, цвета, идентификаторы.
- src/ui: диалоги и уведомления.
- src/editor.mjs: состояние и управление редактором.
- src/styles/editor.css: стили и адаптивность.
- assets: исходные SVG и фоны.
- plugin: готовый плагин и библиотека library.json.
- sources: оригинальное ТЗ, выгрузки и доказательства проверок.
- examples: три SVG и три редактируемых проекта.

Для разработки: npm ci. Команды: npm test, npm run format, npm run build:plugin. Готовые версии включены в комплект.

## Проверки

20 автоматических тестов: семантика, исключения, все названия, общий масштаб, палитры, форматы и упаковка плагина. Поворот проверен в браузере. Адаптивность проверена при 1440, 1024 и 390 px. Актуальный статус в CURRENT.json.

Амире ничего не отправлено.
