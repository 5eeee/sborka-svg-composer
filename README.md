# Сборка SVG

Тестовое задание для Студии Очень. Автор: Владимир Кутомкин.

## Запуск

Нужен Node.js 18 или новее. Без npm-зависимостей и сборки:

```sh
node server.mjs
```

Откройте http://127.0.0.1:8774. Сервер слушает только локальный компьютер. Для проверки ядра: `node --test tests/*.test.mjs`.

Короткое работающее демо: http://127.0.0.1:8774/demo.html. Нажмите «Запустить демо»: за 22 секунды редактор пройдёт 10 шагов с подбором, палитрой, S/L, отдельным задним планом, тремя сюжетами и ручным добавлением. Демо использует отдельный холст без чтения и записи сохранённого проекта.

## Что работает

* Автоматическая сборка сцены по смысловым тегам русскоязычного заголовка. Попробуйте «Обучение без отвлечений», «Накопить на мечту», «Работа с документами».
* Ручное добавление объектов из библиотеки, поиск и импорт своих SVG.
* Перемещение мышью или стрелками, дублирование, удаление, порядок слоёв и отмена.
* Переключение S/L: загружаются соответствующие оригинальные SVG, а не просто уменьшается детализация CSS.
* Три цветовые схемы из исходного Figma, своя палитра JSON, автоматическая перекраска и отдельный фон.
* Векторный экспорт SVG с отдельными группами, исходными path и без встроенного растрового изображения.
* Сохранение и открытие проекта JSON, автосохранение на этом компьютере.

## Архитектура

`prepare_assets.py` однократно выделяет группы из экспортов и рассчитывает плотный viewBox по геометрии. Данные path не перерисовываются. Преобразования композиции находятся во внешнем g. `core.mjs` содержит семантический подбор и раскладку, `app.js` отвечает за SVG DOM, состояние и управление. Сервер только раздаёт статические файлы, личные данные не отправляет.

При создании экземпляра SVG идентификаторы и ссылки на defs изолируются префиксом экземпляра. Цвета заменяются по роли в исходной палитре. Фоновые объекты используют отдельные оригинальные монохромные варианты; объектные акценты не используются в них.

Композиция разбирается на основные предметы и связанные элементы заднего плана. Учитываются явно названные предметы и исключения вроде «без телефона». Позиции рассчитываются по габаритам оригинальных SVG; дополнительные объекты получают места с меньшим пересечением, а все автоматические объекты помещаются в холст. Кнопка «Другой вариант» меняет расположение и связанный предмет заднего плана.

Импорт очищает SVG от script, foreignObject, image, анимации, событий, внешних ссылок и стилевых блоков. Проект принимает только допустимые числовые преобразования и известные идентификаторы.

## Формат палитры

```json
{"background":"#f5f1fc","objects":["#D7CDF5","#F9ECB0","#AA9BF0","#F9A3AA","#7864D7","#FFE3E1","#181817","#FFFFFF"],"backgroundObjects":["#D7CDF5"]}
```

Значения objects соответствуют ролям палитры исходного Figma по порядку. Новые схемы загружаются без изменения программы.

В полной восьмицветной схеме позиции 0 и 4 являются фоновыми тонами, 1, 2, 3 и 5 акцентами, 6 и 7 контрастными нейтральными цветами. Основные объекты могут использовать фоновые тона, фоновые объекты не могут использовать акценты. `backgroundObjects` содержит один или два тона одного оттенка. Палитра с конфликтующими ролями или разноцветным задним планом отклоняется с объяснением. В короткой схеме из 3–12 цветов без `backgroundObjects` цвета считаются объектными, а два отдельных фоновых тона рассчитываются из цвета холста. Пример: examples/palette-short.json.

«Цвет холста» автоматически берётся из выбранной палитры и может быть изменён вручную. «Автоматический задний план» управляет только предметами за основными объектами. Если для идеи нет связанного предмета, задний план не заполняется случайным декором. Отдельный объект можно перевести на задний план вручную.

## Ограничения и честное описание AI

AI использовался при разработке кода и разборе требований (Codex). Во время работы приложения внешний AI API не вызывается. Семантический подбор ограничен локальным словарём и не является универсальной языковой моделью. Для неизвестного смысла редактор предлагает ручной выбор, не генерирует новые объекты и не притворяется, что понял запрос.

Подготовлены веб редактор и плагин Figma. Установка: plugin/README.md. Автономный плагин включает все SVG, версия в аккаунте Figma загружает library.json отдельным файлом. Интерактивная демонстрация находится в demo.html. Работодателю результат не отправлен. Исходная библиотека принадлежит автору тестового; без его разрешения не публикуйте её в открытый доступ.
