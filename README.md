# Сборка

Веб-редактор и плагин Figma для сборки редактируемых векторных композиций из предоставленной библиотеки. Тестовое задание для Студии Очень.

## Быстрый запуск

Требуется Node.js 18+. Распакуйте комплект и запустите `start.cmd` либо `node server.mjs`. Откройте http://127.0.0.1:8774. Для работы готовой версии установка npm-зависимостей не нужна. Сервер слушает только 127.0.0.1.

Короткое интерактивное демо: http://127.0.0.1:8774/demo.html.

## Плагин Figma

Автономный вариант: Figma Desktop → Plugins → Development → Import plugin from manifest → `plugin/manifest.json`. Затем запустите «Сборка» из Development. Векторы встроены, сервер и интернет для работы автономного варианта не нужны.

Версия в библиотеке аккаунта: [открыть плагин](https://www.figma.com/file/new?try-tool-resource-content-id=2137a770-4ae4-432e-8fb5-81003c111a93&try-tool-resource-type=gen_tool&type=design&mode=design). Она получает закреплённую публичную библиотеку и шрифт через интернет. Доступ другого аккаунта к этой ссылке не гарантируется; воспроизводимый путь для получателя — автономный пакет. Публичная публикация в Figma Community не заявляется.

## Работа

1. Введите метафору или названия предметов. Круглая кнопка с искрами предлагает текст идеи; «Собрать идею» собирает композицию.
2. Выберите S/L, формат, цветовую схему. Для своего формата доступны размеры от 200 до 5000 px.
3. Добавляйте предметы из библиотеки, перемещайте мышью или стрелками, редактируйте X/Y и поворот. Дублируйте, удаляйте, отменяйте действия, меняйте порядок слоёв и роль заднего плана.
4. Импортируйте SVG и JSON-палитру. Примеры палитр: `examples/palette.json` и `examples/palette-short.json`.
5. Сохраните проект JSON для продолжения работы либо скачайте SVG. В плагине нажмите «Добавить в Figma» для вставки редактируемых векторов.

## Ограничения

Метафоры разбираются локальным словарём тем и выражений. Неизвестный смысл не подменяется случайным результатом: редактор предлагает выбрать предметы вручную. Внешнего AI API и ключей нет. Новые иллюстрации не генерируются.

10 предметов представлены в двух детализациях, с отдельными монохромными вариантами заднего плана. В комплекте 40 предметных SVG и 6 фонов. Исходные пропорции и общий относительный масштаб сохраняются.

## Архитектура

Модульный монолит: один проект, разделённый на модули подбора, раскладки, палитр и интерфейса. Веб-редактор и плагин переиспользуют одну логику. Монорепозиторий с независимыми пакетами здесь не нужен. Подробности: `ARCHITECTURE.md`.

Для разработки: `npm ci`, `npm test`, `npm run build:plugin`. Готовые файлы плагина находятся в `plugin/`. CI повторяет тесты и сборку на Node.js 20 и 22.
